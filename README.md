This package is the polished black-and-gold mobile MVP matching the preview concept.

1. Home / Top Picks
2. My Picks navigation slot
3. Parlay Builder
4. News & Analysis
5. More
6. Injury & lineup entry point
7. Weather entry point
8. Results entry point
9. Account / billing entry point

- Moneyline
- Spread

- Model probability

- Injury context
- Weather context
- Parlay selection
- News feed placeholder
- Black/gold visual identity
- Mobile-first navigation

## Run locally
npm install
npx expo start

Then open in Expo Go or an emulator.

## Connect live data
Set:
EXPO_PUBLIC_API_URL=https://your-api.example.com

Implement the server endpoints in /server using licensed providers.

## Commercial launch
This release is intentionally analytics-only: it does not accept bets, deposits or payouts.

A $0.99 paid app can sell access to analytics, subject to the current Apple/Google store rules, taxes, billing setup, privacy requirements and any applicable sports-content/data licensing.

## Real-money wagering
Treat real-money sportsbook functionality as a separate regulated product. Licensing, geofencing, age/identity verification, KYC/AML, responsible-gambling controls, payments, security, audit logs and jurisdiction-specific requirements are not included.
